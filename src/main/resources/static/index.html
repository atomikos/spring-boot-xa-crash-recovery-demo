How it works

placeOrder()                      ← one business operation
  ├─① save order ─────────► PostgreSQL · order
  └─② send order id ──────► Artemis · queue "orders"
                                  │
                                  ▼
                           ShippingListener
                                  │ save
                                  ▼
                           PostgreSQL · shipment

One operation writes to two resources — PostgreSQL (the order) and the Artemis queue. The ShippingListener turns the queued message into the shipment. The 💣 crash points sit between these writes.

The business logic of placeOrder() (com.atomikos.demo). The 💣 buttons crash the app between these two steps — and, with Atomikos, mid-commit.
